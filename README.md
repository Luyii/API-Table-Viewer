# API Table Viewer

Chrome DevTools 中的 JSON 接口调试扩展：把数组转换为表格，用内置 JSON 查看器浏览响应，支持搜索定位、请求详情和数据导出。

当前版本 **1.4.13** · Manifest V3 · 无运行时依赖 · 数据在本地处理。

## 安装与开始使用

1. 下载项目源码或扩展 ZIP，完整解压到固定目录。
2. 打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择**直接包含 `manifest.json` 的文件夹**。
4. 打开目标页面的 DevTools，选择 **API Table** 标签，刷新页面并选择 JSON 请求。
5. 从“数据结构”选择数组并打开 Table；点击单元格可查看完整内容。

更新、加载失败排查见 [安装说明](docs/INSTALLATION.md)。

## 功能

| 场景 | 支持内容 |
| --- | --- |
| 捕获接口 | JSON 响应、已有 Network 记录补录、URL / 方法 / 状态筛选、保留导航记录 |
| 表格分析 | 全数组搜索、匹配高亮与跨页定位、排序、分页、显示列、列宽自适应及拖动调整 |
| 查看长内容 | 单元格单行省略；点击后使用内置 JSON 查看器显示完整数据 |
| JSON 浏览 | 普通数据默认展开全部；大数据确认后完整遍历、虚拟滚动；路径跳转与搜索定位 |
| 请求复现 | 请求详情、复制请求体 JSON、复制 Bash 格式 cURL |
| 导出 | 原始响应、当前 JSON 节点、全部筛选和排序后的 CSV / Markdown / JSON |
| 布局 | 左侧列表独立收起、拖动调宽、记住布局和分页偏好 |
| 数值 | 普通整数字面量超出安全整数范围时仍精确保留，支持搜索、排序与导出 |

表格自适应指**列宽**：内容自动宽度通常为 88–380 px，手动宽度通常最高 960 px；完整表头字段名单行所需宽度始终作为下限，超长表头可突破上述上限，通过表格横向滚动查看。长内容不会持续撑高单元格。隐藏列仅影响屏幕显示，导出仍包含全部字段。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| Ctrl / ⌘ + F | 聚焦当前上下文的接口、表格或 JSON 搜索 |
| F3 / Shift + F3 | 下一个 / 上一个匹配 |
| Ctrl / ⌘ + G，配合 Shift | 下一个 / 上一个匹配 |
| 搜索框中 Enter / Shift + Enter | 下一个 / 上一个匹配 |
| Esc | 关闭弹框 |

按键需要焦点位于扩展面板内；Chrome 可能优先处理部分系统快捷键。树节点支持整行点击、Enter / 空格展开与方向键收起。

## 大数据与精度边界

- 单响应最多 **20 MiB UTF-8**；缓存最多 **150 条或 80 MiB 原文**，达到限制时淘汰旧记录。解析对象和界面会占用额外内存。
- 当前子树超过 **5,000 节点、500,000 展示字符或 32 层嵌套**时，先显示提示。点击“按需浏览此数据（展开全部）”后自动遍历全部节点，仅渲染可见窗口。没有“暂停展开”按钮。
- 复制与导出完整数据仍需要处理全部对应数据；极深嵌套的格式化 / 导出可能受序列化调用栈限制。
- 普通超安全整数保持精确；小数和指数形式按 JavaScript Number 处理。需要保留全部原始写法时，使用原始响应复制 / 下载。

## 开发与检查

需要 Node.js 18+；打包另需 Python 3。无需 `npm install`。

```sh
npm test
python3 scripts/package.py
```

Windows 可用 `py scripts/package.py`。扩展安装本身不需要 Node.js 或 Python。

打包产物位于 `dist/API-Table-Viewer-v1.4.13.zip`，解压根目录直接包含清单。源码无需构建即可作为已解压扩展加载。

当前 **76 项回归测试及静态包检查通过**。测试使用真实 Worker 逻辑与模拟 DOM / DevTools；尚未完成真实 Chrome 安装、视觉布局、系统快捷键、剪贴板和下载界面的验证。见 [测试说明](docs/TESTING.md) 与 [本次检查报告](CHECK_REPORT.md)。

## 隐私与许可

扩展不上传捕获的数据，不加载远程代码，清单未申请额外权限。复制 cURL、请求详情和导出文件可能包含接口凭证及业务数据，分享前应自行检查内容。

项目尚未指定开源许可证；创建 GitHub 仓库不代表授予开源使用许可。


## 本地 Chrome 复现环境

执行 `npm run test:manual`，打开 http://127.0.0.1:8765 ，在 API Table 面板打开后发送案例。无需安装依赖；完整数据说明、逐项验收和真实执行记录见 [Chrome 复现指南](docs/CHROME_REPRO.md)。`npm run test:fixtures` 检查 HTTP 数据与真实 Worker 联动，不代表 Chrome 实机通过。
