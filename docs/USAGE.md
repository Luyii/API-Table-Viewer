# 使用指南

适用版本：v1.5.1。返回 [文档中心](README.md)。

## 选择请求与布局

打开目标网页的 DevTools → API Table。左侧列表顶部的“搜索接口”仅按 URL / 路径筛选，可与方法和状态类别组合使用；“保留导航记录”默认开启，关闭后页面导航会清空旧记录。手动“清空”释放响应缓存和会话列宽设置。

左侧标题栏 × 可单独收起列表，顶部按钮重新展开。拖动中间分隔线调整宽度，双击恢复 300 px。Tab 聚焦后可用左右方向键调整，Home / End 到达允许边界。

## 表格

在数据结构树中选择数组，或使用“数组路径”发现嵌套数组。对象数组合并全数组字段；基础类型或混合数组使用 index / value 列。数组路径发现最多扫描 100,000 个节点、列出 200 个数组，其他节点可逐层浏览。

点击表头排序。每页支持 25 / 50 / 100 / 200 条。搜索作用于整个所选数组，结果会自动跳转到第一个匹配单元格并高亮；上一项 / 下一项可跨页跳转。计数按匹配单元格统计。匹配列原本隐藏时会自动显示。

列宽按完整表头和当前见到的内容估算并保留最大自动宽度。字段名保持单行，拖动缩窄也不能低于完整字段名所需宽度；超长字段可突破常规宽度上限，在表格内横向滚动查看。拖动列右边界手动调整，双击边界恢复该列自适应；“适配列宽”重算当前表格。手动列宽在同一请求 / 数组的翻页、搜索和排序后保留，当前会话最多记住 32 个请求 / 数组组合。

普通字段值单击复制完整值，长内容单行省略并提供“查看”入口；对象和数组通过“查看”打开 JSON 查看器，独立“复制”按钮取得完整 JSON。缺失字段显示 `—`，null 显示 `null`，空字符串显示 `""`，缺失字段没有无效的查看入口。

CSV、Markdown、JSON 导出全部筛选结果并保留排序，不受当前分页和隐藏列影响。CSV 使用 UTF-8 BOM，并对字符串进行公式防护；真实负数仍按数值导出。

## JSON 查看器

从单元格、数据结构“查看”或 Raw JSON 的入口打开同一个查看器。普通数据每次打开默认全部展开；超过 README 所列阈值时，确认后自动遍历全部节点并使用虚拟滚动。“收起全部 / 展开全部”是同一个切换按钮，关闭弹框、切换节点或收起全部会释放当前展开任务。

点击对象 / 数组所在整行展开或收起。行内的复制、路径和“进入”按钮独立响应。“进入”将该节点作为浏览起点；支持返回起点、上一级、最大化、复制值、复制路径与下载当前节点。

路径框支持：

```text
root.data[0]
$.data[0]["field.name"]
["data", 0, "field.name"]
```

路径仅读取字段，不执行 JavaScript；无效路径会提示并保留当前视图。

搜索字段名及标量值。后台每批扫描最多 10,000 个节点、返回最多 50 个匹配，可继续下一批。点击匹配在原树中展开祖先、定位正确数组批次、滚动并高亮目标。已发现结果可以向前回看。按需浏览的超长字符串每段 10,000 字符，搜索命中后自动打开对应分段。

大数据虚拟列表使用摘要减少可见区负担，单个长值可以“进入”查看全文。完整复制 / 下载取得当前节点全部内容。

## 请求详情与原始响应

“请求详情”展示 URL、状态、耗时、UTF-8 响应大小、重复 Query 参数、请求 / 响应头与请求体。请求体最多保留 256 Ki 字符，截断会提示。

“复制请求体 JSON”只复制请求体，合法且完整时可用；小于等于 50,000 字符只调整空白，保留原始数字与字符串转义，更大时直接复制原文。

“复制 cURL”生成适用于 Bash / WSL / Git Bash 的命令，不会自动执行。不能完整还原的 multipart / 文件请求或截断请求体会提示使用 Chrome Network 的 Copy as cURL。不要把生成的命令当作 PowerShell / CMD 语法。

顶部“复制 JSON / 下载 JSON”保留原始响应文本。Raw JSON 首屏为受限预览，大数据优先使用查看器或下载原文。

## 字段级响应模拟

双击表格、数据树或 JSON 查看器中的标量，或鼠标悬停字段行后按 F2。Enter / 失焦提交，Esc 取消；无实际改动时只退出输入，不保存或提示成功；实际提交后自动进入编辑模式，不需要额外点击启用。

修改处以轻微底色标记，悬停可看原值。顶部显示修改数量，“查看修改”可核对前后值、定位字段或恢复一项；“退出编辑”清除当前网站的规则。

回到网页重新查询或刷新，真实接口响应会在交给网页前应用字段修改。未修改的字段继续使用最新后端数据。刷新、清空捕获列表和重开面板后保留；其他网站或标签页不共用。关闭标签页、重启浏览器或重新加载扩展后清除。

保持字段类型，不新增 / 删除字段。对象数组按唯一 ID / UUID / key 定位，无唯一标识时使用不超过 64 KiB 的完整行内容匹配；行内容变化、重复或标识失效时跳过。响应超过 1 MiB 也可编辑小字段；当前响应载入上限 20 MiB，单字段上限 64 KiB。

请求仍会执行后端操作，修改不直接重渲染业务页面；退出后需要再次查询或刷新才显示真实值。捕获历史和导出保留原始数据。支持主页面 Fetch 与异步 XHR 的 JSON 文本 / JSON 响应；接口按方法和完整 URL 匹配，不按请求体区分。

操作与限制见 [v1.5.0 发布说明](RELEASE_v1.5.0.md)。

## 搜索范围

- 左侧“搜索接口”只筛选已捕获的接口地址，不搜索响应字段；“清空记录”清除所有捕获记录。
- 右侧数据结构页“搜索字段 / 值”搜索当前响应，点击“搜索定位”或 Enter 打开 JSON 查看器并定位匹配。表格页同名输入搜索当前数组；弹框内搜索当前起点下的字段和值。
- Ctrl / ⌘ + F 优先跟随弹框，其次跟随左侧焦点，再跟随右侧当前表格 / 数据结构；焦点在左侧时不会跳去搜索响应。

## 复制详情文本

进入字符串或其他简单值的详情后，内容区顶部显示“复制内容”。字符串按原文复制，保留真实换行和引号，不额外添加 JSON 外层引号或转义；即使正在查看某个万字符分段，也复制当前节点的全部内容。数字（包括超安全整数）、布尔和 null 使用对应的 JSON 数值文本。原有顶部“复制完整数据”继续复制 JSON 表示，便于保留类型。

## 外观设置

右上角“外观设置”的“整体配色”支持四套预设，也可以在“自定义”中输入一个 `#e2e9df` 格式的色值，或使用旁边的取色器。扩展以此颜色为背景基调，自动生成面板、表格、文字、字段值、边框及状态标记的完整配色，不需要逐项配置。

完整合法色值即时应用并自动保存；不完整或无效输入不改变当前配色，失焦恢复上次有效值。切换预设恢复该主题配色；“恢复默认”重置全部外观，不清除接口记录或字段模拟规则。旧版逐项配色如有页面背景值，会以该值生成整套主题。

强调色、12–16 px 数据字号、紧凑 / 舒适密度和隔行底色仍可单独调整。


## 数组的批量展开与折叠

数据树和 JSON 查看器中的每个数组说明右侧都有符号按钮：`⊞` 直接扁平展开全部层级，`⊟` 恢复一级内容展示。按钮状态独立于行内展开，点击已展开的行后仍可一次扁平展开；不会先关闭内容。点击对象 / 数组行控制当前一级，标签本身不复制；复制使用独立按钮。复制与查看等操作位于行右侧。

扁平展开直接显示数组项，不重复显示同一个 Array 根节点。内容按高度撑开，滚动交给数据树或详情主区域，没有 360 px / 50vh 的内部滚动上限；大数组保留虚拟渲染，只生成窗口附近的 DOM。相邻数组互不影响。

## 顶部收起与浮动搜索

右侧最顶部的无文字细条可收起 / 恢复接口信息、视图标签、工具栏和统计行。收起后按 Ctrl / ⌘+F，浮动显示当前表格或数据树搜索；Esc 关闭浮动区域。当前数据和字段编辑规则保留。

## 捕获状态

顶部捕获状态显示收到的请求、正文不可读和已解析数量；请求包含 HTTP / HTTPS 的 localhost 与其他来源。监听在面板启动时注册，不依赖手动切换视图。正文暂不可读时有限重试；HAR 自带正文时也可读取，并支持带 BOM 的 JSON。若收到为 0，请检查 Chrome Network 是否记录到请求；若已解析但列表为空，请检查左侧筛选条件。
