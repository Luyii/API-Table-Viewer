# 测试

## 自动检查

需要 Node.js 18+ 和 Python 3（预览生成检查），无需安装项目依赖。

```sh
npm test
```

| 命令 | 检查内容 |
| --- | --- |
| `npm run test:regression` | 89 项回归：解析、整数精度、路径、排序、搜索定位、导出、缓存、异步状态、列宽、详情复制和响应编辑 |
| `npm run test:package` | MV3 清单、入口资源、HTML ID、CSP、脚本语法及面板共享作用域 |
| `npm run test:fixtures` | 本地 HTTP 接口与 Worker 联动，包括节点阈值、50,000 条记录、精确整数和长文本 |
| `npm run test:preview` | 示例 HAR、预览 HTTP 路由，以及生成预览的脚本语法和 HTML 标识 |
| `npm run test:fields` | 15 项原位字段 Mock 检查：精确整数、类型、数组定位、大响应小补丁、Fetch / XHR、启动请求、会话恢复、站点隔离与 Worker 路径 |
| `npm run test:appearance` | 5 项外观检查：设置持久化与恢复默认、异常配置回退、强调色可读性、面板关闭与焦点恢复、字号变化后调整列宽 |
| `npm run test:mock` | 18 项：Fetch / XHR 拦截、精确匹配、单次并发、取消、类型、规则更新、租约、面板控制和 HTTP 页面联动 |

回归测试在 Node.js 中运行 Worker 代码，通过模拟 DOM 和 DevTools 对象检查界面逻辑。接口测试使用随机端口，结束后自动关闭服务。2026-10-20 的自动检查结果：78 项回归、静态检查、8 个接口子案例通过。

## GitHub Actions CI

`.github/workflows/ci.yml` 在所有分支的 `push`、`pull_request`（创建、重新打开和更新提交）以及手动触发时运行，不设置路径过滤。

- Node.js 18、22、24 分别执行 `npm test`，覆盖上述全部自动检查；18 用于验证当前声明的最低版本兼容性。
- 所有测试任务成功后，使用 Node.js 24 和 Python 3.12 执行 `python3 scripts/package.py`，再执行 `python3 tests/package-archive.py`。
- ZIP 检查核对打包白名单、重复条目、完整性及文件内容，并对临时解压目录运行现有资源、CSP 和语法检查。版本号从清单读取，无需在 CI 中同步修改。
- 不安装 npm 或 Python 项目依赖，不使用依赖缓存，不发布产物。工作流仅申请仓库读取权限。
- 任一命令失败会使对应任务失败；不同 Node.js 版本继续独立检查。每项任务限时 10 分钟，同一事件和 ref 的新运行会取消旧运行。

本地复现打包检查：

```sh
npm test
python3 scripts/package.py
python3 tests/package-archive.py
```

实际 CI 结果以仓库 Actions 页面为准。自动检查和 ZIP 验证不代表已完成 Chrome 浏览器验收。

2026-10-22 本地验证（Node.js 24.19.0、Python 3.12.14）：`npm test` 的 78 项回归、资源检查和 8 个接口子案例通过（Node 测试报告另计 1 个父案例）；打包及 ZIP 解压资源验证通过。移除 ZIP 中的 `worker.js` 后，验证命令按预期返回非零退出码。工作流通过 actionlint 1.7.12 静态检查。该记录不代表其他 Node.js 版本或 GitHub 托管运行器上的检查已通过。

## 发布检查

1. 运行自动检查并完成对应的浏览器验收。
2. 同步版本号、使用说明和更新记录。
3. 执行 `python3 scripts/package.py`。
4. 解压生成的 ZIP，确认根目录包含 manifest.json，并加载该目录。

响应对比改为延迟执行：编辑和应用时不计算字段差异，网页请求首次命中当前规则后才对比原始响应与已应用正文。同一正文复用对比结果，未应用的草稿不参与；规则内容/状态/模式改变时命中计数重置，防止旧命中被当作新正文已生效。状态由现有 5 秒轮询同步，命中仅表示请求使用了假数据，不保证业务页面成功渲染。2026-10-22 本地 `npm test` 通过：88 项回归、资源检查、8 个 HTTP/Worker 子案例、18 项替换检查、3 项预览检查；尚未完成真实 Chrome 验收。
