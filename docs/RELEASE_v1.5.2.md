# v1.5.2：单色主题定制与测试工程改进

发布日期：2026-10-27；基础版本：1.5.1。

## 主要变更

- 输入一个六位十六进制颜色值或使用取色器，自动生成整套主题配色，包括字段值、表格、编辑与搜索标记、滚动条。
- 主题持久化、恢复预设、非法输入隔离，旧版自定义背景自动迁移为主题基调。
- 新增 10 项请求捕获启动集成测试及 8 项测试选择规则检查；日常 CI 按改动选择测试，正式发布运行完整测试。
- 发布流程从元数据读取版本，校验版本说明和 UNLICENSED 状态；下载并复验同一提交的 ZIP，生成 SHA256，拒绝覆盖已有标签或 Release，先上传草稿再公开。

本次不改变接口捕获、字段模拟协议或许可范围，作为兼容的维护版本发布。

## 安装与升级

从本版本 Assets 下载 API-Table-Viewer-v1.5.2.zip 和 SHA256SUMS.txt，核对 SHA256 后完整解压；manifest.json 应位于解压目录根部。

关闭 DevTools，在 chrome://extensions 开启开发者模式，加载解压目录或重新加载扩展；再打开目标页面 DevTools → API Table 并刷新触发 JSON 接口。需要 Chrome 114+，未发布到 Chrome Web Store。重新加载扩展可能清除会话模拟规则。

参见[安装指南](INSTALLATION.md)、[使用指南](USAGE.md)和[完整变更](../CHANGELOG.md#152---2026-10-27)。
