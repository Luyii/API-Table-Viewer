# v1.5.3 · 数据显示转换

## 更新内容

新增独立的「数据显示」面板，可启用时间戳转本地时间、JSON 字符串结构化查看和空值突出显示。设置会自动保存，并在接口切换、分页及搜索后生效。

时间戳识别 2000–2100 年范围内的 10 位秒及 13 位毫秒值，可能与同长度的业务编号重合。JSON 字符串自动识别限于不超过 100 万字符的有效对象和数组。

## 原始数据

转换只改变显示，原始响应不会被修改；搜索、排序和复制继续使用原始值。

## 验证与限制

包含显示转换和接口捕获启动的自动检查；自动测试使用模拟环境，不代表真实 Chrome DevTools 中的完整端到端验收。
