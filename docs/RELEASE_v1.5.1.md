## 更新概述

本版本改进数组浏览、复制与搜索交互，并修正面板初始化时的请求监听注册。既有字段规则结构和许可状态不变。

## 主要变更

- 数组旁的扁平按钮独立于逐行展开；展开全部后再次点击恢复一级展示。
- 移除重复 Array 根节点和展开区固定高度，统一使用主区域滚动，并保留虚拟渲染与逐行折叠。
- 标量单击复制；对象 / 数组单击行展开，通过右侧按钮复制完整 JSON。
- 顶部细条可收起工具区；收起后按 Ctrl / ⌘+F 显示浮动搜索，Esc 关闭。
- 修正请求捕获启动位置，补充正文有限重试、HAR 内嵌正文及带 BOM JSON 识别，并显示捕获状态。

## 升级步骤

1. 关闭现有 DevTools，替换扩展目录。
2. 在 `chrome://extensions` 重新加载扩展。
3. 重新打开 DevTools → API Table，刷新目标网页后触发接口。
4. 验证捕获、编辑与恢复；重新加载扩展可能清除会话规则，按需重新配置。

详细排查见 [安装与故障排查](INSTALLATION.md)。

## 下载与安装

在本版本 Release 的 Assets 下载 `API-Table-Viewer-v1.5.1.zip`，不要将自动生成的 Source code ZIP 与扩展安装包混淆。可使用同页 `SHA256SUMS.txt` 核对 SHA-256。

1. 完整解压 ZIP 到固定目录，确认 `manifest.json` 直接位于该目录根部。
2. 打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”并选择该目录。
3. 在目标网页打开 DevTools → API Table，刷新网页并触发 JSON 接口。

需要 Chrome 114+。字段模拟仅支持主页面 Fetch 和异步 XHR 的 JSON 文本 / JSON 响应，不覆盖 Worker、iframe、WebSocket 或流式协议；响应查看仍受既有 20 MiB 边界限制。重新加载扩展可能清除会话规则。
