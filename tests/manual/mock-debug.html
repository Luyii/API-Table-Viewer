操作顺序
  1. 点击查询，在插件中选中 /api/mock-orders。
  2. 打开“编辑响应”，修改客户名、状态或金额，点击“启用替换”。
  3. 回到本页，再点击 Fetch 或 XHR 查询，检查表格与下方响应。
  4. 测试初始化请求时，启用规则后点击插件中的“刷新网页并应用”。
  5. 单次规则命中后自动结束；持续规则需手动停用。普通刷新不会自动重新安装规则。
